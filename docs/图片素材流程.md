# 景点图怎么来（已自动化）

> 结论：**不用一张张找。** 纽约/首尔的地标图可以从 Wikipedia / Wikimedia Commons 自动抓，
> 而且接口直接给出**作者和许可证**，正好用来填署名。

## 为什么是 Wikipedia 而不是"纽约版 VisitSeoul"

VisitSeoul 只覆盖首尔。地标照片的通用做法是 **Wikimedia Commons**：

- 几乎每个地标条目都有一张主图，存在 Commons 上
- 每张图都带 `Artist`（作者）和 `LicenseShortName`（许可证）—— 署名要的东西它都有
- 许可以 CC0 / CC BY / CC BY-SA / 公有领域为主，都能用于非商业展示（CC BY 系列要署名）

链路：

```
搜索词 → Wikipedia 条目 → 条目主图文件名 → Commons 查授权 → 下载 1400px 缩略图 + 记录署名
```

搜索词在 `data/photo-queries.json`，**想换词直接改这个文件**。

## 一条命令抓全部

前提：**国内要开代理**（wikipedia.org / commons.wikimedia.org 直连不通；实测 ECONNRESET）。

```powershell
cd C:\Users\l1762\Documents\Codex\interestip

# 先干跑一遍：只查不下载，确认每张都找对了
node scripts/fetch-place-photos.mjs --dry-run

# 没问题就正式抓（--heroes 连两张 hero 一起抓）
node scripts/fetch-place-photos.mjs --heroes
```

产出：

| 位置 | 内容 |
|---|---|
| `D:\interestip-images\places\<id>.jpg` | 地点小图 |
| `D:\interestip-images\hero-seoul.jpg` 等 | hero 大图（用 `--heroes`） |
| `web-preview\assets\credits.json` | 署名（作者 + 许可证），页面会自动显示 |

常用参数：

| 参数 | 作用 |
|---|---|
| `--only nyc-met,nyc-moma` | 只抓指定的几个 |
| `--heroes` | 连 hero 一起抓 |
| `--dry-run` | 只查不下载 |
| `--force` | 已存在的也重抓 |
| `--out <目录>` | 换输出目录 |
| `--limit 5` | 只抓前 5 个（先试水） |

## 首页 hero 图也可以手动换

`--heroes` 抓的是 Wikipedia 上"Seoul skyline night"/"Manhattan skyline"条目的主图，
不一定是你最喜欢的那张。想换的话，把喜欢的图改名成 `hero-seoul.jpg` / `hero-nyc.jpg`
丢进 `D:\interestip-images\` 就行，重跑第 ②③ 步即可。

## 署名这件事

- **CC0 / 公有领域** → 不强制署名，但写上更体面
- **CC BY / CC BY-SA** → **法律上必须署名**（作者 + 许可证）

抓取脚本会把署名自动写进 `web-preview\assets\credits.json`，
页面在图片下面显示。手动找的图，自己往这个 json 里加一条即可：

```json
{
  "nyc-met": "Photo: 作者名 / CC BY-SA 4.0 / via Wikipedia"
}
```

**来源不明的图不要用** —— 这个项目最值钱的就是"每条都说得清来源"。

## 出问题怎么办

| 现象 | 原因 / 办法 |
|---|---|
| `ECONNRESET` / 超时 | 代理没开，或代理没走全局。开着代理再跑 |
| 某个条目"没找到带图的条目" | 换 `data/photo-queries.json` 里的搜索词，或手动找一张 |
| 抓到的图不对（是别的东西） | 同上的办法：换搜索词，`--only <id> --force` 重抓 |
| 图太小 / 太大 | `check-images.mjs` 会标出来，换一张 |
